# Surface: Damla marketing site (docs/index.html)

Mode: Persuade. Visitor: Mac user (often a developer running Claude Code / Codex) deciding whether to install. Action: copy the Homebrew command or download the DMG. Proof: the panel itself, rebuilt live in HTML from the real UI (demo data, like the README screenshots). Constraints: static HTML/CSS/JS on GitHub Pages from /docs, TR + EN toggle, Reduce Motion honored, no invented claims (no users, ratings, press).

Chosen direction: Ebru, drops on water (IMPECCABLE’S PICK, chosen by the user on my recommendation). Memorable moment: the notch drips pigment into a dark water tray and the visitor's scroll combs it; the panel melts out of the site's own notch.

## Direction contract

THESIS: Damla means drop. The page is an ebru tray: pigment falls from the notch onto dark water, and scrolling pulls combs through it. Refuses the notch-app default of a MacBook render, glass cards and a feature grid.

OWN-WORLD: deep ox-gall water ink (#0c111d) as ground; pigments with jobs: coral = music, saffron/amber = agents, mint = files, indigo = sound, rose + bone white for accents. Real marbling math on canvas (drop displacement, tine combs, vortex). Pulled-paper sheets with white held edges carry the finale. Funnel Display / Funnel Sans, JetBrains Mono only for commands. The site nav is a black notch.

STORY: the visitor sees a notch doing something, learns what the panel shows (music, agents, files, sound), sees the rest as a swatch book of named ebru patterns, trusts the privacy, installs.

FIRST VIEWPORT: full-bleed water tray; a real-scale black notch fixed at top center acting as nav; drops fall from it and bloom into rings in the upper half; headline bottom-left at display size; install block (brew command with copy, DMG button) bottom-right; macOS 26+, free and open source line.

FORM: Ebru marbling tray, position 1 on my ordered list, seed key 9604aec5.

SIGNATURE INTERACTION: a pinned stage where the panel melts out of the notch and changes page as you scroll; each page drops its pigment and a comb stroke passes; track changes recolor panel and water; the approval card can actually be answered. Motion grammar: drops fall and bloom (ease-out), combs are scroll-reversible, everything else still.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
